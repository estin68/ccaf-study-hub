# CCA-F Study Hub

A self-contained study hub for the **Claude Certified Architect (Foundations)** certification (CCA-F). Built with plain HTML/CSS/JS — no build step, no dependencies.

## Pages

- **Home** (`index.html`) — course overview, section cards, quick navigation
- **Study Guide** (`study-guide.html`) — organized study notes and review material
- **Practice Exam** (`practice-exam.html`) — **77** interactive questions across **3 banks** — Exam 1 (Foundation, 50 Qs), Exam 2 (Platform &amp; Day-2, 13 Qs) and Exam 3 (Scenario Review, 14 Qs). Run any bank, combine all, or filter per-domain, with instant scoring, per-domain results, and full answer explanations. Timed, random-shuffle (20 Qs) mode included.
- **Cheat Sheet** (`cheatsheet.html`) — a print-friendly **1-page exam-day cheat sheet** of must-memorize facts (models, tokens/sampling, prompt patterns, Messages API, HTTP error codes, tool loop/MCP, RAG, safety/guardrails).

## Content coverage

Claude models &amp; capabilities · LLM core concepts · prompt engineering · the developer platform / Messages API · tool use, MCP &amp; agents · RAG &amp; context engineering · safety, guardrails &amp; deployment.

## Live site

Hosted on **GitHub Pages**. Visit: https://estin68.github.io/ccaf-study-hub/

Just open `index.html` in any browser — no server required.
