# CCA-F Study Hub

A self-contained study hub for the **Claude Certified Architect (Foundations)** certification (CCA-F). Built with plain HTML/CSS/JS — no build step, no dependencies.

## Pages

- **Home** (`index.html`) — course overview, section cards, quick navigation
- **Study Guide** (`study-guide.html`) — organized study notes and review material
- **Practice Exam** (`practice-exam.html`) — interactive practice questions with instant scoring

## Live site

Hosted on **GitHub Pages**. Visit: https://estin68.github.io/ccaf-study-hub/

## Local usage

Just open `index.html` in any browser — no server required.
